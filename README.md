# AI Learning Platform

A modern web platform for AI learning featuring an interactive chat interface, user authentication, and a beautiful dark theme UI.

## Features

- 🤖 AI Chat Interface
- 🔐 User Authentication
- 🌙 Dark Theme
- ✨ Particle Background Effects
- 💰 Pricing Plans
- 📱 Responsive Design

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Heroicons
- TSParticles

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser

## Deployment

This project is optimized for deployment on Vercel. To deploy:

1. Push your code to a GitHub repository
2. Visit [Vercel](https://vercel.com)
3. Import your repository
4. Deploy!
